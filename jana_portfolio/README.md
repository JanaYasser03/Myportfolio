# Jana Yasser Portfolio

A responsive single-page portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools are required.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in the contact section and JavaScript.
- Replace the LinkedIn and GitHub placeholder destinations with your actual profile URLs.
- Add real repository links to each project.
- Replace illustrative project mockups with authentic screenshots when available.
- Verify all dates and training statuses are still accurate.
- The contact form prepares a message in the visitor's email app; it is not a server-side form.

The site intentionally omits Achievements and Testimonials because no genuine content was provided for those sections.
